# Orvia Beta 签名页改版设计

日期：2026-08-26

## 目标

优化 `https://beta.ice329.me/` 的首屏使用体验，让测试者打开页面后能立即理解：

1. 这是 Orvia 记账软件的测试安装页面；
2. 需要上传 p12、描述文件和密码；
3. 签名通常需要约 1 分钟；
4. 签名完成后可以获得 iPhone 安装入口；
5. 当前版本和更新记录位于页面下方。

## 范围与约束

- 只修改 `worker/src/site.js` 中公开签名页的 HTML、CSS 和提示文案。
- 保留现有表单字段名：`p12`、`mobileprovision`、`password`。
- 保留现有接口：`POST /api/sign`、`GET /api/status/{taskId}`、`GET /api/release`。
- 保留任务轮询、刷新恢复、错误处理和安装链接生成逻辑。
- 保留当前 Bundle ID 文案：`com.ice.Orvia`。
- 不修改 GitHub Actions、签名脚本、Worker 签名服务、后台管理页或其他产品页面。
- 不新增外部字体、图片 CDN、前端框架或其他运行时依赖。

## 页面结构

公开页采用移动端优先的单栏布局，顺序如下：

### 1. 品牌与任务说明

- 使用简洁的 Orvia 品牌标题和视觉标记。
- 说明 Orvia 是一款用于记录收入与支出的个人记账软件。
- 展示当前 Bundle ID `com.ice.Orvia`。
- 以短提示说明上传材料只用于当前签名任务，不在页面中保存。

### 2. 签名材料卡片（首要区域）

- 标题明确写为“上传签名材料”。
- p12 文件、描述文件、密码保持原有控件和校验属性。
- 桌面宽屏使用两列文件输入布局，小屏自动变为单列。
- “开始签名”作为唯一主要操作按钮，保持现有 `id="submit"`。
- 按钮附近提示“签名过程通常需要约 1 分钟，请不要关闭页面”。

### 3. 状态与安装卡片

- 保留现有 `id="status"` 状态区域和 `id="install"` 安装链接。
- 视觉上区分等待、处理中、成功和失败状态，但不改变原有状态文本更新逻辑。
- 成功后显示安装入口。
- 增加友好提示：建议在 iPhone Safari 中打开安装链接；其他浏览器可能无法直接唤起 iOS 安装流程。

### 4. 版本与更新信息

- 将现有 `id="release-panel"` 放在状态和安装区域之后。
- 保留当前版本、发布日期、摘要、变更列表和历史记录的数据来源与 DOM id。
- 当前版本使用较明显的版本信息卡片，历史更新记录使用紧凑的列表呈现。
- 当没有发布信息时继续显示现有的空状态，不影响签名页使用。

## 视觉方向

- 保持轻量、可信、易读的浅色界面。
- 使用蓝色作为主要操作和链接颜色，使用柔和的渐变背景和细边框建立层次。
- 卡片圆角、阴影、间距统一，文件上传区域比普通说明文字更醒目。
- 键盘焦点、按钮禁用态、错误文本和窄屏布局必须保持清晰可见。
- 不通过动画表达业务状态，不增加会阻塞签名提交的交互。

## 交互与兼容性

- 提交动作仍由现有表单监听器处理，新增布局不能改变 `FormData(form)` 的结果。
- 刷新页面后仍按现有逻辑恢复最近任务状态。
- 表单提交期间保留现有按钮禁用行为。
- 不假设测试者使用 Safari；页面文案只给出 iPhone Safari 的推荐，并明确其他浏览器可能不支持 `itms-services` 唤起。
- 保持现有 Content Security Policy，不引入新的脚本来源。

## 验证方案

### 静态验证

- 页面源码中签名表单位于版本面板之前。
- 三个字段的 `name`、`id`、`accept` 和必填属性未改变。
- 现有 API 路径和轮询逻辑未改变。
- `com.ice.Orvia`、约 1 分钟提示和浏览器安装提示存在。

### 自动化验证

- 更新页面测试，覆盖签名表单优先、更新面板在下方和新增提示文案。
- 运行现有完整测试套件和 JavaScript 语法检查。
- 执行 Wrangler dry-run，确保 Worker 构建正常。

### 部署后验证

- `https://beta.ice329.me/` 返回 HTTP 200。
- `/api/release` 仍能正常返回，不改变发布数据接口。
- `/api/sign` 的现有签名流程继续可用；不在本次改版中更换测试证书或签名服务。
- 在 iPhone 上检查页面顺序、上传控件、处理中提示和成功后的安装入口。

## 非目标

- 不实现 p12 自动托管、证书长期保存或匿名上传权限。
- 不改签名链路、GitHub Actions、R2 文件命名或 Worker API 合约。
- 不在本次改版中修改 `ice329.me` 主站、WeChatBill、王者自动点击或管理后台其他模块。
